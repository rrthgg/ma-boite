Installer

Trois minutes, et c'est parti.

Le jeu est un programme Python. Il se lance en local, sans compte ni connexion.

Installer Python

Téléchargez Python sur python.org. Sous Windows, cochez « Add python.exe to PATH » pendant l'installation.

Télécharger le jeu

Récupérez ma_boite.zip et extrayez-le dans un dossier.

Lancer

Ouvrez un terminal (PowerShell sous Windows) dans ce dossier, puis :

python -m pip install -r requirements.txt

python ma_boite.py

La première commande installe Pillow, qui sert à créer l'image de votre résultat à partager. Le jeu fonctionne aussi sans. Sous macOS et Linux, remplacez python par python3.
