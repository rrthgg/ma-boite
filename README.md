# Ma Boîte

Simulation d'entreprise : huit secteurs, jusqu'à 10 concurrents en mode classique, 100 entreprises en mode battle royale.

## Jouer

1. Installer Python 3.10 ou plus récent (python.org ; sous Windows, cocher « Add python.exe to PATH »).
2. Dans ce dossier : `python -m pip install -r requirements.txt` (Pillow, pour l'image à partager ; facultatif).
3. Lancer : `python ma_boite.py`

## Le site

`index.html` est la page d'accueil publiée sur Render ; `ma_boite.zip` contient les fichiers du jeu à télécharger.
Après chaque mise à jour du jeu, remplacer `ma_boite.py`, `moteur.py` et `ma_boite.zip`.
